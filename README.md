# 🥬 Fresh Veggie Store

A simple Vegetable Store website built using HTML5 and CSS3.

## 🌱 About the Project

Fresh Veggie Store is a basic frontend website designed to display fresh vegetables, prices, and store contact information.

## ✨ Features

- Homepage with store branding
- Navigation menu
- Vegetable product sections
- Product names and prices
- Contact details
- Store location
- Footer section

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid

## 📂 Project Structure

```text
Vegetable_Store/
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run

1. Clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` using Live Server.
4. View the website in your browser.

## 🎯 Learning Outcomes

- HTML page structure
- CSS styling
- Flexbox navigation
- CSS Grid layouts
- Frontend website development
